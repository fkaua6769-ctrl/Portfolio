# Portfólio Pessoal - Kauã Ferrari

**Aluno:** Kauã Ferrari

## Descrição do portfólio
Site de portfólio pessoal criado para apresentar meu perfil profissional, habilidades, projetos desenvolvidos e formas de contato.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Devicon
- GitHub Pages

## Link do site publicado
[https://github.io](https://github.io)

## Funcionamento do projeto
O site funciona em uma única página com menu fixo no topo que leva o visitante até as seções de Perfil, Projetos e Contato. Ele também conta com um banner rotativo (carousel) e se adapta automaticamente ao tamanho da tela de computadores e celulares.

## Recurso novo adicionado
Foram adicionados efeitos de animação ao passar o mouse nos cards, textos com botões sobre os slides do banner e melhorias visuais nas cores e divisões da página.

## Como o recurso foi implementado
- **Animação nos cards:** Foi usado CSS (`transition` e `:hover`) para fazer os cards subirem suavemente quando o mouse passa por cima.
- **Banner e cores:** Foram criadas legendas centralizadas sobre os slides com JavaScript para troca de imagens e estilos CSS para deixar o visual mais moderno.
